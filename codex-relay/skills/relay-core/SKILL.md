# Relay Core — 通用中继工具

## 适用场景
- 用户需要了解当前有哪些工业软件可用
- 用户需要确认或取消一个高风险动作（烧录、擦除、覆盖文件）
- 用户需要收集某个动作或任务的日志和产物
- 用户在执行具体软件操作前想先检查适配器状态
- 用户提到"适配器""确认""日志""产物""系统状态"等关键词

## 可用工具速查
| 工具 | 用途 | 风险 |
|------|------|:---:|
| `list_adapters` | 列出可用工业软件适配器及状态 | 🟢 低 |
| `confirm_action` | 确认或取消高风险动作 | 🟢 低 |
| `collect_logs` | 收集指定动作/任务的日志和产物 | 🟢 低 |

## 标准工作流

### 查询系统状态
1. 调用 `list_adapters(filter="")` → 获取全部适配器状态
2. 向用户报告：哪些软件可用、哪些不可用、原因是什么

### 确认高风险动作
1. 当 `run_action` 返回 `status="confirmation_required"` 时
2. 向用户说明：即将执行什么操作、风险是什么
3. 等待用户明确指示
4. 调用 `confirm_action(action_id="...", confirm=true/false, reason="用户确认/取消")`

### 收集日志排查问题
1. 动作执行后：调用 `collect_logs(action_id="...")` 收集该动作的日志
2. 任务结束后：调用 `collect_logs(task_id="...")` 收集整个任务的日志
3. 需要原始输出时：设置 `include_raw_output=true`

## 何时停止问人
- 遇到 `confirmation_required` 状态时——绝不自动确认破坏性操作
- 适配器全部不可用时——报告原因，询问用户是否需要安装软件
- 日志中发现 `severity="fatal"` 错误时——报告并停止
- 同一动作连续失败 3 次时——报告并停止
